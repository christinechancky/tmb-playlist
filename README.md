# tm.bucketlist

A small phone web app for our band's song Wishlist and setlists. Songs live in our Google Sheet; this app talks to a Google Apps Script attached to that sheet.

- App: https://christinechancky.github.io/tmb-playlist/
- Setup guide for bandmates: https://christinechancky.github.io/tmb-playlist/guide.html

No passcodes or personal data are stored in this repository. Each person enters the band passcode in the app once; it stays on their phone.
