Build the share button

Adds a song straight from Apple Music, Spotify or YouTube, without opening Safari. You build it once (about 15 minutes), then share it to the band with an iCloud link.

Blue = a variable: tap the field, then pick it from the grey bar above the keyboard (or Select Variable).

Start

0Open Shortcuts. Delete the old “Add to Band List” (long-press → Delete). Tap +, name the new one Add to Band List.
1Add Receive … from Share Sheet (search “Share Sheet”). Tap its blue input type, Clear, tick only URLs and Text. Set “If there’s no input” to Get Clipboard.

Your details

2Add Text: type the band passcode.
Then Set Variable: name it Passcode (input: Text).
3Add Text: type your name.
Then Set Variable: name it Name (input: Text).

Find the song

4Add Get URLs from Input, input: Shortcut Input.
5Add Get Item from List: First Item from URLs.
Then Set Variable: Link (input: Item from List).

Pick tags

8Add Get Contents of URL. Paste this, then add Passcode straight after the =:
https://script.google.com/macros/s/AKfycbzswaVsXYB0DPty0aZCgYmRWARO2pVadsKLBwYTOOw3G24aXReZmbozZ3hg-pYoyDS4/exec?action=options&key=
9Add Get Dictionary Value: Get Value for shortcutTags in Contents of URL.
10Add Choose from List, input Dictionary Value. Tap the ⌄ arrow: Prompt Tags, turn on Select Multiple.
11Add Combine Text: Chosen Item with New Lines.
11bAdd If: Combined Text contains New tag. Inside it (above “Otherwise”):
Ask for Input, prompt New tag name → then Set Variable: newtag (input: Provided Input).

Send to the band sheet

12Add Get Contents of URL. Paste this as the URL:
https://script.google.com/macros/s/AKfycbzswaVsXYB0DPty0aZCgYmRWARO2pVadsKLBwYTOOw3G24aXReZmbozZ3hg-pYoyDS4/exec
Tap ⌄: Method POST, Request Body JSON. Add 6 fields (each Text):
actionadd
keyPasscode
addedByName
urlLink
tagsCombined Text
newTagnewtag
Then Set Variable: Result (input: Contents of URL).

Questions (“Probably on the list as …”, which artist)

13Add Get Dictionary Value: status in Result.
14Add If: Dictionary Value is confirm. Put steps 15–18 inside the If (above “Otherwise”).
15Get Dictionary Value: pendingId in Result. Then Set Variable: Pending.
16Get Dictionary Value: message in Result. Then Set Variable: question.
17Get Dictionary Value: options in Result.
Then Choose from List, input Dictionary Value. Tap ⌄: Prompt question. Leave Select Multiple off.
18Get Contents of URL, same URL as step 12, POST, JSON, 4 Text fields:
actionconfirm
keyPasscode
pendingPending
choiceChosen Item (from step 17)
Then Set Variable: Result (input: Contents of URL).

Done message

19After “End If”: Get Dictionary Value: message in Result.
20Show Notification: Dictionary Value. Tap Done.

Test it

In Apple Music, tap Share on a song → Add to Band List. Pick tags → Done. A notification should say Added: …. The first time, iOS asks to allow connections to script.google.com: tap Always Allow.

Share it with the band

Long-press the shortcut → Share → Copy iCloud Link. Your passcode and name are inside, so each bandmate must change steps 2 and 3 to their own name after adding it. (Or, in the shortcut’s settings, use “Import Questions” for those two Text actions, so iOS asks them when they add it.)
